# Exercise 1. Matrix Size and Entries

**Given:**

A = [[2, -1, 3], [0, 4, 5]]

B = [[1, 0], [-2, 3], [4, 1]]

## 1. State the sizes of matrices A and B.

The size of a matrix is determined by the number of rows and columns. We write the number of rows first and the number of columns second.

- Matrix A has 2 rows and 3 columns.

Answer: A = 2 × 3

- Matrix B has 3 rows and 2 columns.

Answer: B = 3 × 2

## 2. Find the entries a₁₂, a₂₃, b₂₁, and b₃₂.

The first subscript indicates the row, and the second subscript indicates the column.

a) Finding a₁₂:

In matrix A, we select row 1 and column 2.

a₁₂ = -1

b) Finding a₂₃:

In matrix A, we select row 2 and column 3.

a₂₃ = 5

c) Finding b₂₁:

In matrix B, we select row 2 and column 1.

b₂₁ = -2

d) Finding b₃₂:

In matrix B, we select row 3 and column 2.

b₃₂ = 1

## 3. Write the second row of A and the first column of B as vectors.

a) The second row of matrix A:

The second row contains the entries 0, 4, and 5.

Answer: (0, 4, 5)

b) The first column of matrix B:

The first column contains the entries 1, -2, and 4.

Answer: (1, -2, 4)
